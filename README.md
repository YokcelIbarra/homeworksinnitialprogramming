# Homeworks Initial Programming

Proyecto de consola desarrollado en C# con .NET para resolver 15 ejercicios básicos de programación.

El programa incluye un menú interactivo que permite seleccionar cada ejercicio y trabajar conceptos como:

- Condicionales.
- Ciclos.
- Operaciones matemáticas.
- Manejo de cadenas.
- Validación de datos.
- Uso de métodos.
- Operadores aritméticos y lógicos.

## Ejecución

Para ejecutar el proyecto:

```bash
dotnet run
